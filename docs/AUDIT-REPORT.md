# Audit report (Phase 1)

Scope: logic and correctness, security and privacy, offline, sync and the service worker, UX and typography, accessibility and
i18n, and performance on a throttled mid-range Android profile. Method: read-only review by parallel agents, with
reproductions in Node and in headless Chrome against the built `dist/`, plus the Semgrep and by-hand work in
`docs/SECURITY-SCAN.md`. Nothing was fixed in this pass except the placeholder and branding items marked FIXED.

**Severity.** *Blocker*: breaks the live MVP flow, or breaks a non-negotiable on the demo path. *Major*: wrong or misleading
output, data loss off the main path, or an accessibility failure. *Minor*: polish, edge cases and hygiene.
**Status.** CONFIRMED means reproduced or traced in code. SUSPECTED means not reproduced. IDs: `A-nn` are first-pass findings,
`L1` logic, `L2` security and privacy, `L3` offline and sync, `L4` UX, accessibility and i18n, `L5` performance
(section 5). "(= x)" means the same root cause as another row.

Effort: S under an hour, M under half a day, L longer.

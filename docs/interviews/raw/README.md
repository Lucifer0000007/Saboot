# Raw interview notes

The original notes, one file per conversation, named by its id in `src/data/fieldEvidence.ts` (`I-01.md`, `I-02.md`, …).
Anonymous: no name, shop name, village name or phone number. Keep them as written; the grammar-edited version lives in
`src/data/fieldEvidence.ts` and `docs/INTERVIEWS.md`. A theme, figure or quote may enter the data file only if it is in the
note here, and a quote only word for word. After editing the data file: `node --import ./scripts/ts-resolve.mjs scripts/interviews-doc.mjs`.

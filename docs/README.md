# Saboot docs

Start with the top-level [README](../README.md). Saboot is a front-end simulation; values are labelled LIVE, REPLAY,
SIMULATED or HAND. It does not decide claims, eligibility or amounts.

## Judges and quick start
- [BUYER-ONE-PAGER.md](BUYER-ONE-PAGER.md): the problem, who uses Saboot and what it does not do, on one page.
- [USP-MVP.md](USP-MVP.md): the USP, the MVP scope and the demo path (Phase 3).
- [FINAL-REPORT.md](FINAL-REPORT.md): what was done on the final-prep and mobile-final branches, in plain language.
- [SCENARIO-FACTS.md](SCENARIO-FACTS.md): every scenario number the docs quote (generated by `npm run gen`).
- [Saboot-Complete-Guide.docx](Saboot-Complete-Guide.docx): a Word copy of the overall guide for offline reading; it may
  lag the Markdown docs.
- [The one-page visual explainer](../.archify/explainer-saboot-20261022-053216/saboot-explained.html): a snapshot made
  with the archify tool; open it locally. Its numbers are not checked by `npm run facts:check` and may lag.
